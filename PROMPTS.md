# Рабочие промпты

Проверенные промпты для типовых задач проекта. Добавляйте свои; помечайте,
что сработало хорошо, а что пришлось дорабатывать.

## 1. Регистрация нового материала

```
В materials/ добавлен файл <имя>. Изучи его, кратко опиши содержание,
период данных, качество (пропуски, аномалии) и добавь запись в SOURCES.md
с оценкой надёжности. Предложи, для каких гипотез из PROJECT.md он полезен.
```

## 2. Баланс времени мельниц

```
По источникам <S-00N> построй баланс календарного времени по каждой мельнице:
работа / плановые ремонты / внеплановые простои (по причинам) / прочее.
Посчитай коэффициенты готовности и использования, выдели топ-5 причин потерь.
Результат — в analysis/, с указанием допущений.
```

## 3. Анализ темпа (т/ч)

```
Проанализируй часовую производительность мельниц по <S-00N>: распределение,
разброс по сменам/бригадам/сезонам, связь с крупностью питания, плотностью,
мощностью двигателя. Оцени потенциал «работать как лучшие смены».
```

## 4. Подготовка к интервью

```
Подготовь гайд интервью для <роль> (45 минут): цели, 10–12 вопросов
по производительности мельниц, какие данные запросить по итогам.
```

## 5. Фиксация решения

```
Зафиксируй в DECISIONS.md решение: <что решили>. Основание: <...>.
Принял: <кто>. Дата — сегодня.
```

## 6. Итоговый документ

```
Собери в outputs/ <документ> для <аудитория> на основе analysis/ и DECISIONS.md.
Каждая цифра — со ссылкой на источник. Отдельно — допущения и открытые вопросы.
```

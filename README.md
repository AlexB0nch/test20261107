# Повышение производительности мельниц — ОФ, Якутия

Консалтинговый проект по операционным преобразованиям: рост производительности
мельничного передела (измельчение) на обогатительной фабрике в Якутии.

Репозиторий — это **проектная память**: контекст, решения, источники, рабочие
промпты, исходные материалы, аналитика и итоговые документы в одном месте.

## Структура

| Путь | Назначение |
|---|---|
| `README.md` | Этот файл: что за проект и как устроен репозиторий |
| `PROJECT.md` | Контекст, цель, KPI, стейкхолдеры, сроки, риски |
| `DECISIONS.md` | Журнал решений: дата, решение, основание, кто принял |
| `SOURCES.md` | Реестр источников: файл, содержание, дата, надёжность |
| `PROMPTS.md` | Рабочие промпты консультанта для работы с Claude |
| `CLAUDE.md` | Инструкция для Claude: о проекте и правилах работы |
| `materials/` | Исходные материалы от клиента и внешние данные (только чтение) |
| `analysis/` | Рабочая аналитика: расчёты, гипотезы, черновики, заметки интервью |
| `outputs/` | Итоговые документы для клиента: отчёты, презентации, планы |

## Как работать

1. Новый файл от клиента → кладём в `materials/` и **сразу** регистрируем в `SOURCES.md`.
2. Любой расчёт или разбор → `analysis/`, со ссылкой на источники из `SOURCES.md`.
3. Принято решение (по объёму, гипотезам, методике, рекомендациям) → запись в `DECISIONS.md`.
4. Готовый документ для клиента → `outputs/`, с датой и версией в имени файла.
5. Изменился контекст (сроки, стейкхолдеры, цель) → обновляем `PROJECT.md`.

## Именование файлов

`ГГГГ-ММ-ДД_краткое-описание_vN.расширение`, например
`2026-11-07_баланс-времени-МШЦ_v1.xlsx`.

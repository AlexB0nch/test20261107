# Реестр источников

Каждый файл в `materials/` (и важный внешний источник) регистрируется здесь.
На источники ссылаемся по номеру (S-001) в аналитике и решениях.

## Шкала надёжности

- **A — высокая:** первичные данные систем (АСУТП, MES, энергоучёт), официальная отчётность.
- **B — средняя:** выгрузки/сводки, подготовленные персоналом клиента; журналы, заполняемые вручную.
- **C — низкая:** устные оценки из интервью, презентации, оценки экспертов без данных.
- **D — не проверено:** публичные/внешние источники, требующие подтверждения.
